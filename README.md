# open-brain-lmstudio

Self-hosted Open Brain MCP server (capture + semantic search over personal
notes) backed by Docker Compose and a local LM Studio instance for
embeddings and metadata extraction. No cloud API keys. No ingestion/scraping
jobs. Two containers: Postgres+pgvector, and the MCP server.

Forked from [NateBJones-Projects/OB1](https://github.com/NateBJones-Projects/OB1)'s
`integrations/kubernetes-deployment` — see `NOTICE` for attribution.
